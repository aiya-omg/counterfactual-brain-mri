## 3. pseudo Dice 0.545 は報告値ではない

ここが今回いちばん重要な取り違えだった。

nnU-Net が学習中に表示する pseudo Dice は、**検証集合全体を1つの集合として計算した
大域 Dice** である。分子分母を全症例で合算するため、大きな病変が値を支配する。

段階2で SENORA を評価するときに使うのは症例ごとの Dice なので、
同じ土俵で比べるにはソース内も症例ごとに測らなければならない。

| 指標 | 値 |
|---|---|
| 症例ごとの Dice 中位値 | **0.132**（IQR 0.000–0.461） |
| 症例ごとの Dice 平均 | 0.271 |
| 大域 Dice | 0.271 |
| 学習中の best EMA pseudo Dice | 0.545 |

0.545 と 0.132 のあいだに矛盾はない。違う量を見ていただけである。

なお学習完了後の自動検証は最終エポックの重みで走る。best 重みでの数字が必要なので
`nnUNetv2_train 501 3d_fullres 0 --val --val_best` を回し直した
（中位 0.144 → 0.132 と、best のほうがわずかに低い。大域では 0.269 → 0.271）。

## 4. なぜ Dice が出ないのか

`evaluate_source_baseline.py` を書いて要因を分解した。

### 4.1 病変が小さい

| 体積 | 例数 | Dice 中位 | 再現率 中位 |
|---|---|---|---|
| 0–1 mL | 8 | 0.000 | 0.000 |
| 1–5 mL | 11 | 0.000 | 0.000 |
| 5–20 mL | 11 | 0.258 | 0.267 |
| 20 mL 以上 | 11 | 0.633 | 0.611 |

体積と Dice の Spearman ρ = 0.76（p < 0.0001）。5 mL 未満が41例中19例を占め、
この層は丸ごと 0.000 である。

小病変で Dice が落ちること自体は ISLES'22 の公式報告と同じ傾向だが、
本研究では小病変の比率が高いため影響が大きい。

### 4.2 FLAIR 上に病変が見えていない

ISLES 2022 の病変マスクは **DWI 空間で描かれた急性期梗塞**である。
超急性期には DWI に写る梗塞が FLAIR にまだ現れない。これは DWI-FLAIR ミスマッチとして
発症時刻の推定に使われている確立した現象である。

マスク内の信号を組織中位値との比で見て、1.3 超の割合を高信号率とした。

- 高信号率 中位 0.401
- 高信号率が 0.5 未満の症例: **29 / 41**
- 高信号率 0.5 以上の群（12例）: Dice 中位 **0.573**
- 0.5 未満の群（29例）: Dice 中位 **0.065**

つまり「FLAIR 上に手がかりのない領域を FLAIR から当てろ」という解けない課題が
7割の症例に混ざっている。

### 4.3 4.1 と 4.2 は分離できていない

小病変では部分容積効果で高信号率も下がるため、体積と可視性は相関する（ρ = 0.49）。
体積を層別すると可視性と Dice の関係は有意でなくなる（0–5 mL で ρ = +0.31 p = 0.20、
5 mL 以上で ρ = +0.35 p = 0.11）。方向は一貫しているが n が足りない。

残り4 fold を回して205例で層別すれば分離できる。

### 4.4 登録誤差は主要因ではない

素朴に相関を取ると round-trip Dice と Dice が ρ = −0.51（p = 0.0006）となり、
「登録が正確な症例ほど成績が悪い」という逆向きの関係に見える。これは交絡である。

- round-trip Dice と体積の相関: ρ = −0.41
- round-trip Dice = 1.000 の群（35例）: 体積 中位 3.6 mL、Dice 中位 0.065
- 1.000 未満の群（6例）: 体積 中位 35.1 mL、Dice 中位 0.719

小さいマスクは最近傍で写しても形が保たれて 1.000 になりやすく、大きいマスクは
境界のボクセルがずれてわずかに 1.000 を割る。round-trip Dice が体積の代理変数として
働いているだけで、受理基準を上げても改善しない。

## 5. SENORA への適用

`predict_senora_armc.py` を書いて段階2を予備実行した。

### 5.1 頭蓋除去

設計書は SynthStrip を指定していたが、FreeSurfer は Windows で WSL を要する。
**HD-BET 2.0.1** を使った。nnU-Net と同じ研究室の脳抽出モデルで、FLAIR を含む
複数コントラストで学習されている。`pip install hd-bet --no-deps` で入る
（`--no-deps` は `argparse` バックポートが標準ライブラリを隠すのを避けるため）。

アームC 16例すべてで成功した。設計書からの逸脱として記録する。

頭蓋除去は輝度正規化の前提としても必須である。Dataset501 の plans は
`use_mask_for_norm = True` で計画されており、背景が 0 で埋まっていることを前提に
非ゼロ領域だけで z-score を取る。SENORA をそのまま入れると頭皮と頭蓋を含んだ
統計で正規化され、ドメインシフトを測る実験に前処理の不一致が混ざる。

### 5.2 結果

| 指標 | 値 |
|---|---|
| Dice 中位値 | **0.000**（IQR 0.000–0.000） |
| Dice 平均 | 0.015 |
| Dice 0 の症例 | 12 / 16 |
| 予測が完全に空だった症例 | 8 / 16 |
| 最良の症例 | sub-003、Dice 0.222 |

性能が下がったのではなく、モデルが何も出していない。

### 5.3 パイプラインの不具合ではない

同じ `nnUNetv2_predict` 経路で ISLES の検証症例を推論すると、
Dice 0.206（ISLES_0018）と 0.524（ISLES_0195）で妥当な出力が出る。
予測ボクセル数も 24万・30万と正常。CLI 経路と重みは健全である。

## 6. 原因は撮像分解能の不一致

| | 断面内 | 断面外 | スライス数 |
|---|---|---|---|
| ISLES 2022 FLAIR（学習元） | 0.71 mm | **0.71 mm** | 約350 |
| SENORA アームC（対象） | 0.72 mm | **6.8 mm** | 21〜24 |

断面外の間隔が約 **10 倍**違う。

nnU-Net は推論時に入力を学習時の間隔へ再標本化する。SENORA の20数枚のスライスから
200枚以上の断面を補間で作り、それを 128³ のパッチとしてモデルに渡している。
引き伸ばされた断面には実際に撮像された情報がないため、学習時とはまったく違う
立体が入力される。

**これは前処理で吸収できるずれではない。** 学習元が等方 0.71 mm である限り、
5〜7 mm 厚の対象に対して入力分布が一致しない。

輝度については、頭蓋除去後の非ゼロ平均が SENORA 約320〜390、ISLES 約900〜1100 だが、
z-score 正規化がスケールを吸収するのでこれ自体は問題にならない。

## 7. 設計上の含意

段階2の主張は「ソース内 Dice と SENORA での Dice の差」である。
ソース内 0.132、SENORA 0.000 では**低下幅として観測できるものがない**。

さらに、設計書 5.2 の対照実験は C1（5 mm リサンプル）を**評価時の劣化**として
与える設計だった。今回の結果は、分解能差が劣化の一段階どころか予測を消滅させる
規模であることを示している。劣化は評価時ではなく**学習時**に反映する必要がある。

### 選択肢

| 案 | 内容 | 代償 |
|---|---|---|
| **E（推奨）** | ISLES 2022 FLAIR を SENORA と同等の断面外間隔（5〜7 mm）に落として学習し直す | 再学習に約20時間。ソース内 Dice の上限も下がる |
| A | ISLES 2015 SISS へ学習元を変更 | 亜急性期・FLAIR ネイティブ。訓練28例と少ない |
| B | FLAIR 上で高信号の症例に限って学習・評価 | 課題設定が変わる。除外基準の事前登録が必要 |
| C | DWI + ADC に戻しアームAを主軸に | 解析集団が16例から7例に減る |
| D | 現状を「FLAIR 単一チャネルの限界」として報告 | 主張が外部検証から課題設定の分析に変わる |

案 E は設計の骨格を変えずに済み、「学習元を対象の撮像条件に合わせる」という手順が
RQ2（低下の要因分解）とも整合する。A と E は排他ではない。

## 7.5 案E の実装（同日着手）

案E で進めることにした。`degrade_isles_resolution.py` を書いて ISLES 2022 FLAIR 205例を
SENORA の撮像幾何へ落とし、Dataset502 として再学習を開始した。

### 何を再現したか

SENORA アームC の実測は厚み 5.0 mm・間隔 6.8 mm が16例中12例。1.8 mm のギャップがあり、
組織の 73.5% しか撮像されていない。厚みだけを再現して間隔を詰めると、実際には存在しない
連続性を与えてしまうので、ギャップも再現する。

処理は RAS 正順に揃えたうえで、頭尾方向に 6.8 mm ごとに出力スライスの中心を置き、
各中心の前後 2.5 mm に入る元スライスを平均する。励起されたスラブ内の信号平均に相当する。
中心間の残り 1.8 mm はどの出力スライスにも寄与しない。面内は ISLES 0.71 mm と
SENORA 0.72 mm でほぼ一致するので変更しない。

マスクは同じ窓の中で陽性ボクセルの割合を取り、多数決（0.5）で2値化した。

### 結果

| 項目 | 値 |
|---|---|
| スライス数 | 352 → 37（中位）。範囲 17〜38。SENORA は 21〜24 |
| 病変体積 | 7.13 → 6.48 mL（中位）。**体積の 97.4% が残る** |
| マスクが空になった症例 | 4 / 205（いずれも 0.21 mL 未満） |
| Dataset502 の症例数 | 198（空になった4例と、元から空だった3例を除外） |

多数決で薄い病変が消えることを懸念していたが、体積の97.4%が残り、消えたのは
0.21 mL 未満の4例だけだった。「どれか1ボクセルでも陽性」とした場合の体積
（中位 9.90 mL）は元より膨らむので、多数決のほうが妥当と判断した。

### nnU-Net の計画

再計画で狙いどおりの構成になった。

| | Dataset501（旧） | Dataset502（新） |
|---|---|---|
| 目標間隔 | 0.71 × 0.71 × 0.71 mm | **6.80 × 0.71 × 0.71 mm** |
| パッチ | 128 × 128 × 128 | **20 × 256 × 224** |
| バッチ | 2 | 3 |
| カーネル | 全段 3×3×3 | 前3段は 1×3×3、ストライド 1×2×2 |

断面外の間隔が SENORA と一致したので、推論時に断面を補間で作る必要がなくなった。
前3段が断面内のみを畳み込む異方性カーネルになっており、薄い積層に適した形である。

### 学習の立ち上がり

88秒/エポック（1000エポックで約24時間）。エポック8時点で pseudo dice 0.36、
best EMA 0.276。Dataset501 の同時期と同程度の立ち上がりで、発散の兆候はない。

完走後は `evaluate_source_baseline.py` を Dataset502 に向けて検収し直し、
通れば `predict_senora_armc.py` で段階2をやり直す。

## 9. 補足: つまずいた点

- **再開フラグは `--c`。** `-c` は `unrecognized arguments` で落ちる
- **`pandas` の `DataFrame.attrs` は `concat` / `merge` で失われる。**
  大域 Dice を attrs に入れていて `KeyError` になった。戻り値に変えた
- **SourceTree が別クローンを開いていた。**
  `Documents\counterfactual-brain-mri` が origin をローカルの Desktop に向けており、
  履歴も独立していたため `refusing to merge unrelated histories` が出ていた。
  作業対象は `Desktop\AI医学` のみ
- **HD-BET の出力は入力と同じファイル名。** `_bet` 接尾辞は付かないので、
  nnU-Net の `_0000` 規約をそのまま維持できる
