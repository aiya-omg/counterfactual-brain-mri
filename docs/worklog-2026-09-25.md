# 作業記録 2026-09-25

## 1. 方針転換: アームAを主軸に戻す

Dataset502（案E）でも SENORA アームCの Dice 中位は 0.000 のままだった。
病期を並べると、アームC 16例は慢性期11例・不明5例で急性期は0例。
慢性期の大きな梗塞は空洞化して FLAIR で中心が低信号になる。

| 症例 | 病期 | 病変 | マスク内の低信号割合 | 予測 |
|---|---|---|---|---|
| sub-060 | 慢性 | 213 mL | 49% | 0.04 mL |
| sub-017 | 慢性 | 63 mL | 35% | 0 mL |
| sub-010 | 不明 | 23 mL | 72% | 1.2 mL（Dice 0） |

急性期だけの ISLES で学習したモデルは、この見え方の病変を学習していない。
分解能を揃えても動かなかった差は病期のずれと判断した。

決定:

1. アームA（DWI + ADC、7例）を主軸にする。ISLES 2022 の DWI + ADC を
   SENORA の DWI 幾何へ落として学習する（Dataset503）
2. アームCは「急性期で学習したモデルは慢性期梗塞がほぼ見えない」を結果として扱う。
   比較用に慢性期で学習したモデル（ATLAS v2.0、T1w）を足す。
   T1w 上のマスクがないことは、同一検査の T1w→FLAIR 剛体登録で解決できる
   （ISLES の DWI→FLAIR と同じ手間）。ATLAS はデータ利用申請が必要
3. ISLES 2015 SISS（亜急性・28例）と「FLAIR で見える症例だけに絞る案」は優先度を下げる

## 4. 新しい所見: アームAの病変も大半は拡散制限を示さない

入力を確認する途中で、病変内の信号が急性期梗塞の形になっていないことに気づいた。
段階0.6 の特徴づけ（`mask_characterization.csv` の `frac_hyper`）は DWI の
**第1ボリューム、つまり b0** で測っていた（`only_first_volume = True`）。b0 は
T2 強調に近いので、高信号でも拡散制限の証拠にはならない。

b1000 と ADC で測り直した（中央値の比。分母は病変以外の脳）:

| 症例 | 病変(mL) | b0 | b1000 | ADC | 解釈 |
|---|---|---|---|---|---|
| sub-037 | 38.9 | 1.62 | **2.95** | **0.49** | 拡散制限あり。典型的な急性期 |
| sub-099 | 14.5 | 1.29 | 1.56 | 0.81 | 軽度の制限。境界的 |
| sub-071 | 0.7 | 2.37 | 1.80 | 1.33 | T2 shine-through。制限なし |
| sub-014 | 86.2 | 1.84 | 1.01 | 1.52 | ADC 上昇。亜急性期後半〜慢性期 |
| sub-043 | 5.1 | 2.03 | 0.96 | 1.92 | 同上 |
| sub-052 | 61.1 | 1.70 | 0.88 | 1.61 | 同上 |
| sub-086 | 23.2 | 2.22 | 0.66 | 2.31 | 同上。ADC は CSF に近い |

生データの単一ボリュームの run（`dwi_run-01`, `dwi_run-03`、bval 1000）は
ADC マップだった。正規化済みの `desc-ADC` と比が一致している。

`participants.tsv` の `presentation_status` は7例とも acute だが、これは受診時の
臨床区分であって画像上の病期ではない。**画像上で急性期と言えるのは1〜2例。**
ISLES 2022 のラベルは拡散制限域（梗塞コア）なので、アームAにも課題のずれが残る。

含意:

- アームAの Dataset503 の結果は、症例ごとに拡散制限の有無と対応づけて読む。
  「拡散制限のある sub-037（と sub-099）では検出でき、残りでは外れる」が事前の予測
- 23例全体で見ると、SENORA の病変はほとんどが急性期を過ぎている。
  慢性期で学習したモデル（ATLAS v2.0）の比較は、アームCだけでなく研究全体の中心になる
- 段階0.6 の `frac_hyper` は b1000 で測り直す必要がある（`characterize_masks.py` の修正）
