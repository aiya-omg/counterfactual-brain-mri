## データ

| データセット | 病変の出どころ | 予測 | 解析セット |
| --- | --- | --- | --- |
| ISLES 2022（244例） | 専門家マスク | 5-fold 交差検証の out-of-fold 予測 | 主解析 |
| SENORA マスク付き（22本） | 読影医マスク（DWI 7本、FLAIR から DWI へ剛体位置合わせ済み 15本） | 5-fold アンサンブル | 主解析 |
| SENORA マスクなし（虚血性、評価可能な症例） | ADC 急性コアの塊（2026-09-27 の 302daae で固定した定義） | 5-fold アンサンブル | 副解析のみ |

- ISLES ではアンサンブル予測を使わない。`fold_{0..4}/validation/` の検証予測だけを使う。
- fold 0 の `validation/` にある NIfTI は、最終重みの summary を書いたあとで best 重みの検証によって上書きされている。fold 1〜4 の `validation/` は最終重みである。指定されたディレクトリをそのまま使う。
- SENORA の sub-027 は除外する。sub-086 は同一マスクが1本だけなので、その1本を使う。
- マスクなし症例の塊は ADC < 620 で選ばれているので、主解析に入れない。
- 計算は DWI のグリッドで行う。ADC はリサンプリングしない。shape または affine が一致しなければ止める。
- ボクセル体積はヘッダーの affine から計算する。
- ADC の絶対閾値（620）を使う前に、脳内の正の値の中央値から単位を ×10⁻⁶ mm²/s に揃える。帯は 200〜2000（倍率 1）、0.2〜2.0（倍率 1000）、0.0002〜0.002（倍率 10⁶）で、重なったり該当がなければ `adc_unit_unknown` とする。比の計算では単位は相殺される。
- ISLES の脳マスクは保存されていない。`config/stage_curve.yaml` の `isles.brain_dir` が TODO のあいだは抽出しない。

## 病変

- 参照を 26 近傍の 3D 連結成分に分ける。
- 主解析は 0.1 mL 未満を除く。感度分析は 0.5 mL 以上に限る。
- マスクなし症例の参照は、脳内で ADC < 620 かつ b1000 > 1.3 × 正常実質、26 近傍、0.5 mL 以上、重心が脳の下 30% より上、という 302daae の定義。この参照を作るときの正常実質は、病変を除かない脳実質（ADC 200〜1500）の中央値とする。脳全体の ADC 中央値が 500〜1500 の外の症例は評価不能として除外する。

## 正常実質（比の分母）

症例ごとに1つ。

- 脳マスクから、参照・予測・急性コアの塊を合わせて膨張した領域、ADC > 1500、ADC < 200、脳の下 30% のスライスを除く。
- 膨張と収縮の 1 ボクセルは、面で接する近傍（6 近傍）の 1 回とする。膨張は 3 ボクセル。
- 急性コアの塊は正常実質の b1000 が要るので、先に参照と予測だけを除いて仮の正常値を作り、塊を決めてから、塊も含めて除き直す。
- 残った ADC の中央値が 600〜1000 の外なら `qc_flag` に記録する。症例は落とさない。

## 病変の特徴

- 主解析の ADC 比は、病変内 ADC の中央値 ÷ 正常実質 ADC。
- ほかに 10・90 パーセンタイル、1 ボクセル収縮後の中央値（収縮後 27 ボクセル未満は欠損）、ADC < 620 の割合、b1000 の比。
- 検出は、予測と病変の重なりが病変の 10% 以上。感度分析は、1 ボクセルでも重なる場合と、50% 以上。
- 予測は nnU-Net の argmax による二値をそのまま使う。
- log(体積 mL) は 1 mL で 0。テント下は重心が脳の下 30% にある場合。
- ADC 比が 0 以下、または非数の病変はモデルから外し、本数を記録する。

## 統計モデル

主解析は ISLES と SENORA マスク付き。

`detected ~ log(ADC 比) + log(体積) + (1 | 患者)`

- ED50（1 mL）= exp(−β₀ / β₁)。ED90（1 mL）= exp((logit(0.9) − β₀) / β₁)。
- 95% 信頼区間は、患者を復元抽出してモデルを当て直すクラスター・ブートストラップ（2000 回、パーセンタイル法、seed 20260928）。
- 同じ患者が複数回選ばれたときは、抽出ごとに別の患者 ID を付ける。
- 収束しなかった回は信頼区間から外し、回数を記録する。
- 分離は `detectseparation` で確認する。係数の絶対値が 10 を超える場合も分離とみなす。分離があれば `blme::bglmer` を使い、標準化した予測変数の固定効果に正規分布（SD 2.5、切片は SD 10）を置く。ED50 は元の尺度に戻してから計算する。分離の有無と、どちらのモデルを使ったかを記録する。

感度分析は、検出の定義（1 ボクセル、50%）、最小体積 0.5 mL、収縮後の ADC 比、テント下を除く、データセットの固定効果（探索的）、マスクなし症例の塊を加える、の 6 つ。それぞれ ED50 と ED90 を主解析と並べる。

探索的に、b1000 の比を加えたときの ADC 比との相関と VIF を報告する。ADC 比 0.8〜1.5 の病変数を数える。

ボクセル単位の曲線は、主解析と同じ 2 データセットの病変ボクセルを ADC 比 0.1 刻みにし、予測に含まれる割合を患者単位のブートストラップで区間推定する。推定値としては病変単位の主解析を優先する。
