# 事前登録: 慢性期データで学習した nnU-Net を SENORA に当てる（解析 S2）

2026-10-27。この文書は、慢性期モデルの学習を始める前、かつ SENORA に当てる前に書いた。
SENORA 側の画像・マスク・急性期モデルの結果は、これまでの解析ですでに見ている。

## 目的

急性期データで学習したモデル（Dataset503、DWI と ADC）は、ADC 比が上がると検出が落ち、
体積 1 mL の ED50 は 1.18 だった（解析 S1）。SENORA の正解マスクの大半は ADC が上がった陳旧性梗塞である。
同じ SENORA の病変に、病期の合った慢性期のデータで学習したモデルを当て、次を確かめる。

- 慢性期モデルなら陳旧性病変を拾えるか。拾えれば、急性期モデルの Dice の低下は病期の違いで説明できる。
  拾えなければ、装置・集団・正解の定義など SENORA 側の要因が残る。
- 検出の境目が、学習データの病期に応じて ADC 比の上で入れ替わるか。

## モデル

| 名前 | Dataset | 学習元 | 入力 | 状態 |
|---|---|---|---|---|
| 慢性期 FLAIR | Dataset504_ARCFLAIRThick | ARC（OpenNeuro ds004884、CC0） | FLAIR | これから学習 |
| 急性期 FLAIR（対照） | Dataset502_ISLES22FLAIRTHICK | ISLES 2022 | FLAIR | fold 0 のみ学習済み。fold 1〜4 を追加で学習する |
| 急性期 DWI | Dataset503_ISLES22DWIThick | ISLES 2022 | DWI + ADC | 5 fold 学習済み |

慢性期 FLAIR と急性期 FLAIR は、入力・撮像幾何の劣化・頭蓋除去・学習設定をそろえ、学習データだけが違う。
ただし学習データの違いには、病期のほかに装置（ARC は 3 T、ISLES は 1.5 T と 3 T）、施設、
病変の描き方（ARC は T2 強調画像上、ISLES は DWI 上）も含まれる。

### 学習元 ARC の作り方

- ARC の病変マスクは、ある 1 回の撮像の T2 強調画像上に描かれている。FLAIR は別の日の撮像であることが多い。
  セッション名は発症後の日数なので、マスクごとに日数差が最小の FLAIR を選び、**差が 90 日以下**の症例を使う
  （228 例中 108 例）。全例が発症後 6 か月以上で、この間に病変の形は変わらないとみなす。
- T2 強調画像を FLAIR に剛体登録し（相互情報量、`register_isles_flair.py` と同じ設定）、
  マスクを FLAIR の格子へ線形補間で写して 0.5 で二値化する。
- FLAIR に HD-BET（TTA あり、1 例ずつ）をかけ、脳の外を 0 にする。ISLES の FLAIR は配布時点で頭蓋除去済み、
  SENORA の FLAIR も HD-BET で頭蓋除去しているので、それに合わせる。
- `degrade_isles_resolution.py` と同じ方法で、SENORA の FLAIR の撮像幾何（厚さ 5.0 mm、間隔 6.8 mm）に落とす。
  マスクはスラブ内の多数決で二値化する。
- 除外する症例:
  - RAS 正順に並べたときの頭尾方向のボクセル間隔が 2 mm を超える FLAIR（厚いスライスからは 5 mm スラブを作れない）
  - 登録後のマスク体積が T2 格子の体積の 0.8〜1.25 倍の外
  - 写したマスクのうち脳マスクの中にある割合が 0.5 未満
  - 劣化後にマスクが空になった症例（Dataset502 と同じ）
- 108 例のうち 20 例は 2D の FLAIR（`acq-tir2`、頭尾方向 3.2 mm）で、1 つ目の規則で外れる。
  学習に使えるのは多くて 88 例（3D の FLAIR、約 1 mm）。この数は規則を書いたあと、2 例の試運転で分かった。
- ARC は失語症のコホートで、病変はすべて左半球にある。nnU-Net の標準の拡張（左右反転を含む）をそのまま使う。

### 学習

nnU-Net v2.8.1、`3d_fullres`、標準の `nnUNetTrainer`、1000 エポック、fold 0〜4。
SENORA への適用は 5 fold のアンサンブルで、最終の重み（`checkpoint_final.pth`）を使う。
Dataset502 の fold 1〜4 も同じ設定で学習し、対照も 5 fold のアンサンブル・最終の重みにそろえる。

## 評価の対象

SENORA の正解マスクのある 22 例（sub-027 は除外、sub-086 は 1 本）。解析 S1 と同じ。

- **FLAIR マスクの 15 例**（慢性 10、不明 5）: FLAIR の元の格子で評価する。入力は `armc_senora_d502/flair_stripped`
  （Dataset502 の評価と同じ頭蓋除去済み FLAIR）、正解は同じフォルダの `masks`。
- **DWI マスクの 7 例**: FLAIR に同じ方法で HD-BET をかけて入力にする。予測は DWI の格子へ写して評価する。

病変単位の解析は、解析 S1 と同じく DWI の格子で行う。FLAIR の格子の予測を DWI の格子へ写すとき:

- FLAIR マスクの 15 例は、正解マスクを写したときと同じ変換を使う。`stage_senora_lesions.py` の `register` は
  乱数の種とスレッド数を固定しているので計算し直せる。`registration_qc.csv` の `used` 列が `registered` なら登録後、
  `header` ならヘッダの座標のまま。計算し直した変換で正解マスクを写し、保存済みの DWI 格子のマスクと
  Dice 0.99 以上で一致することを確かめてから使う。
- DWI マスクの 7 例は、ヘッダの座標のまま写す（同じ検査内の撮像）。
- 線形補間で写して 0.5 で二値化する。

病変の定義・ADC 比・検出（重なり 10% 以上）は解析 S1（`docs/prereg-stage-curve.md`）と同じ。
特徴量は S1 の `lesions.csv` の SENORA_masked の行を使い、予測だけを差し替えて `detected` を計算し直す。

## 予想

### C1（主）: 陳旧性病変を慢性期モデルは拾う

FLAIR マスクの 15 例で、症例ごとの Dice（FLAIR の格子）を比べる。

- **C1a**: 慢性期 FLAIR の Dice は急性期 FLAIR より高い。対応のある Wilcoxon 符号順位検定、片側、α = 0.05。
  同順位（両方 0 など）は Pratt 法で扱う。
- **C1b**: 慢性期 FLAIR の Dice 中央値は 0.30 以上。当たりか外れかだけを報告する。

### C2: 境目が入れ替わる

DWI の格子の SENORA の 43 病変で、モデルごとに検出の有無を出す。

- **C2a**: ADC 比が 1.18（S1 の ED50）以上の病変で、慢性期 FLAIR の検出割合は急性期 DWI より高い。
  差の 95% 信頼区間を、患者を単位にしたブートストラップ 2000 回（乱数の種 20261027、パーセンタイル法）で求め、
  下限が 0 を超えれば当たり。
- **C2b**: ADC 比が 0.8 未満の病変で、急性期 DWI の検出割合は慢性期 FLAIR 以上。病変数が少ないので判定せず、数だけを記述する。

### 探索（判定しない）

- 慢性期 FLAIR の ARC 内の交差検証 Dice（学習元での性能。急性期 DWI の 0.826 に対応する値）
- 慢性期 FLAIR を ISLES の FLAIR（Dataset502 の画像、急性病変）に当てたときの症例ごとの Dice
- SENORA で右半球と左半球の病変の検出割合（ARC は左半球だけ）
- 慢性期 FLAIR の検出割合を ADC 比に対して描いた曲線。S1 と同じ混合モデルを当てるが、43 病変・22 人なので区間は広い

## 結果の読み方を先に決めておく

- C1a と C1b が当たれば、SENORA の陳旧性病変は病期の合ったモデルなら拾える、と書く。
- C1a が外れ、慢性期 FLAIR の Dice も低ければ、病期の違いだけでは説明できない。
  装置・集団・正解の定義（ARC は T2 上の病変、SENORA は FLAIR 上でグリオーシスを含む）が残る、と書く。
- どちらの場合も、22 例・43 病変からの推定であり、確証は別のデータで行う。
